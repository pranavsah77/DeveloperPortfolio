# DeveloperPortfolio

A portfolio of coursework completed for a **CS Fundamentals Capstone Project**. The repository organizes lab submissions and supporting evidence across Linux, shell scripting, APIs, and professional portfolio development.

## Repository contents

- **[`Linux/`](Linux/)** — Linux lab submissions and command-output evidence.
- **[`ShellScripts/`](ShellScripts/)** — Shell scripting lab submissions and Bash automation evidence.
- **[`API/`](API/)** — API-related lab submissions, including response data and Python-script evidence.
- **[`Portfolio/`](Portfolio/)** — Portfolio coursework, including a roadmap and professional materials.

Most submissions are provided as PDF files, with some image or other supporting evidence. Browse the folders above to view individual lab work.

## Getting started

No installation or build steps are required. Open the PDF and image files directly in your browser or with a compatible viewer.
